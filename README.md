# 🌙 MOONCRUST CHATBOT

**Mooncrust** adalah asisten rekayasa perangkat lunak dan arsitektur sistem (*Senior Staff Software Engineer & Full-Stack Architect*) yang dikembangkan oleh **Bagaskara Amukti Palapa** (Sumatera Selatan, Ogan Komering Ulu Timur, Buay Madang, Kurungan Nyawa).

---

## 🚀 Fitur Utama

- **🧠 Multi-Tier Architecture Intelligence**:
  - `mc-noob`: Model respons cepat dan efisien.
  - `mc-pro`: Model standar rekayasa perangkat lunak dan arsitektur sistem.
  - `mc-expert`: Model analisis mendalam (*deep technical reasoning*).
  - `mc-advance`: Model arsitektur sistem skala besar dan optimasi performa tinggi.
- **🔒 Keamanan Berlapis (Enterprise-Grade Security)**:
  - *Fail-Closed Authentication Gate*: Menolak akses otomatis bila konfigurasi kunci belum terpasang.
  - *Timing-Safe Token Comparison*: Perlindungan dari inferensi waktu pada verifikasi token.
  - *Cryptographic Subresource Integrity (SRI)*: Menjamin keaslian seluruh pustaka CDN pihak ketiga.
  - *HTTP Security Headers*: HSTS, `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, dan `Referrer-Policy`.
  - *Payload Limit*: Batas keamanan muatan untuk mencegah eksploitasi kuota.
- **⚡ Fast Serverless Delivery**: Dioptimalkan untuk performa tinggi dengan arsitektur serverless modern.
